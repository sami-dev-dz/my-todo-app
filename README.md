# Atmos Todo App

A streamlined, high-performance task management application built with the modern web stack. This project demonstrates a focus on clean UI/UX, state persistence, and responsive design principles.

## 🚀 Key Features

- **Intuitive Task flow**: Manage tasks across three distinct states: *Todo*, *In Progress*, and *Done*.
- **Persistence**: Leveraging `localStorage` for seamless state retention across sessions.
- **Responsive Design**: Mobile-first architecture ensures a premium experience on all devices.
- **Modern Tech Stack**: Built with Next.js 16 (App Router), TypeScript for type safety, and Tailwind CSS 4 for utility-first styling.
- **Zero Hydration Mismatch**: Optimized client-side rendering patterns to ensure stable initial loads.

## 🛠 Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **State Management**: React Hooks (`useState`, `useMemo`, `useEffect`)
- **Icons**: Custom SVG / Lucide-React (Ready for expansion)

## 📦 Getting Started

### Prerequisites

- Node.js 18.x or later
- npm or yarn

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sami-dev-dz/atmos-weather.git
   cd atmos-weather
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Run the development server**
   ```bash
   npm run dev
   ```

4. **Build for production**
   ```bash
   npm run build
   ```
